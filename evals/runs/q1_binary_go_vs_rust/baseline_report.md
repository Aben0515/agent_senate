# 單一模型直接分析報告：3 人新創 B2B SaaS 後端：Go 還是 Rust？

## 決策題目
3 人新創團隊做 B2B SaaS 後端，預計一年內拓展至 500 家企業客戶，團隊熟 Python：該選 Go 還是 Rust？

## 方案優缺點概述
對於該技術決策，各方案各有其適用情境與取捨：
- **Go 語言**：具備良好的技術特性，但在不同團隊規模下需權衡學習成本與架構演進。
- **Rust 語言**：具備良好的技術特性，但在不同團隊規模下需權衡學習成本與架構演進。

## 推薦建議
建議團隊綜合評估自身成員的熟悉度、未來的業務規模預期以及維運資源配置。若重視即時交付，可考慮 go；若重視極限性能或未來擴展，可考慮 rust。

## 風險提示
需要注意技術債累積、人才招募困難與系統架構過度複雜之風險。
