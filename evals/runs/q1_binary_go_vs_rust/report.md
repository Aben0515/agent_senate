# 虛擬內閣決策裁決報告：3 人新創團隊做 B2B SaaS 後端，預計一年內拓展至 500 家企業客戶，團隊熟 Python：該選 Go 還是 Rust？

## 一、一句話結論

> **推薦方案：Go 語言（`go`）**（模擬勝率：97%，加權總分：8.45，信心評級：高）
>
> 在當前情境事實約束下，強烈推薦 go 作為最優解。

經過完整交叉質詢與敏感度分析，go 在交付速度、維運簡單度與團隊心智負擔上取得決定性領先優勢。

**翻盤條件**：
- 若業務規模或核心約束在未來幾個月內發生 10 倍以上突變，方需考慮改選 rust

## 二、問題框定與情境約束

**決策題目**：3 人新創團隊做 B2B SaaS 後端，預計一年內拓展至 500 家企業客戶，團隊熟 Python：該選 Go 還是 Rust？

### 候選方案
- `go` **Go 語言** — 高開發速度、廣泛招募池、生態完備
- `rust` **Rust 語言** — 極致性能、無 GC 停頓、編譯期記憶體安全

### 情境事實（硬性約束）
- 團隊規模為 3 名工程師，具豐富 Python 經驗
- B2B SaaS 後端，預計一年內 500 家企業客戶
- 尖峰負載約 200 ~ 1,500 RPS，瓶頸 95% 在資料庫與外部 API

### 採納之前提假設
- **業務優先活下來並驗證 PMF**（原因：界定資源優先級；若不成立影響：重大時程延誤）
