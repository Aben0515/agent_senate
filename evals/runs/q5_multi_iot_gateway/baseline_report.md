# 單一模型直接分析報告：IoT 邊緣閘道器資料收集服務（3 選項）

## 決策題目
IoT 閘道器（ARM、256MB RAM、需遠端 OTA 更新）資料收集服務：該選 Rust、Go 還是 C？

## 方案優缺點概述
對於該技術決策，各方案各有其適用情境與取捨：
- **Rust**：具備良好的技術特性，但在不同團隊規模下需權衡學習成本與架構演進。
- **Go**：具備良好的技術特性，但在不同團隊規模下需權衡學習成本與架構演進。
- **C 語言**：具備良好的技術特性，但在不同團隊規模下需權衡學習成本與架構演進。

## 推薦建議
建議團隊綜合評估自身成員的熟悉度、未來的業務規模預期以及維運資源配置。若重視即時交付，可考慮 rust；若重視極限性能或未來擴展，可考慮 c。

## 風險提示
需要注意技術債累積、人才招募困難與系統架構過度複雜之風險。
