# 完整辯論逐字稿：客服對話摘要功能（每日 5 萬次呼叫、含敏感客戶個資）：該自架開源 LLM 還是使用雲端商業 API？

> 建立時間：2026-11-03T14:25:33.680Z

## 決策簡報與情境約束

- **問題**：客服對話摘要功能（每日 5 萬次呼叫、含敏感客戶個資）：該自架開源 LLM 還是使用雲端商業 API？
- **候選方案**：`cloud_api_with_anonymization` (雲端商業 API + 本地去識別化前置代理)、`self_hosted_open_llm` (自架開源私有化 LLM (vLLM))
- **情境事實**：
  - 客服系統每日處理 5 萬通客服對話，內含電話、地址與信用卡後四碼
  - 符合金融法規要求，若使用雲端 API 需做去識別化；若自架開源模型則需自購 GPU 伺服器並負擔高昂電費與維運
- **預設假設**：
  - 業務優先活下來並驗證 PMF
- **評估準則**：`regulatory_compliance` 個資法法規合規與審計安全性、`summary_quality` 長文本對話摘要品質與精準度、`tco_infrastructure` 基礎設施三年總持有成本 (TCO)、`ops_simplicity` 維運簡單度與 SLA 保證、`scalability_concurrency` 尖峰流量彈性伸縮、`vendor_lockin` 供應商鎖定防範
