# 單一模型直接分析報告：客服對話摘要功能隱私與個資選型

## 決策題目
客服對話摘要功能（每日 5 萬次呼叫、含敏感客戶個資）：該自架開源 LLM 還是使用雲端商業 API？

## 方案優缺點概述
對於該技術決策，各方案各有其適用情境與取捨：
- **雲端商業 API + 本地去識別化前置代理**：具備良好的技術特性，但在不同團隊規模下需權衡學習成本與架構演進。
- **自架開源私有化 LLM (vLLM)**：具備良好的技術特性，但在不同團隊規模下需權衡學習成本與架構演進。

## 推薦建議
建議團隊綜合評估自身成員的熟悉度、未來的業務規模預期以及維運資源配置。若重視即時交付，可考慮 cloud_api_with_anonymization；若重視極限性能或未來擴展，可考慮 self_hosted_open_llm。

## 風險提示
需要注意技術債累積、人才招募困難與系統架構過度複雜之風險。
