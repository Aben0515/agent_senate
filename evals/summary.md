# Agent Senate 評測基準報告 (Evaluation Benchmark Summary)

本評測旨在回答核心命題：**「多 Agent 圓桌辯論到底有沒有比單次直接詢問大模型更強？」**

評測流程採用嚴格的 **雙盲評審機制（Blind Review with Positional Swap）**：
- 對同一題目，分別取得「單一模型 Baseline」與「Agent Senate 虛擬內閣」報告。
- 隨機指派為 Report A 與 Report B（進行 A/B 位置互換以抵銷前後位置偏差）。
- 盲審評審依據 6 大維度（各 1–10 分）：
  1. **具體性**（數字/量級/具名技術）
  2. **考量廣度**（多維度覆蓋）
  3. **盲點揭露**（挖掘被忽略的風險與假設）
  4. **可行動性**（是否提供低成本下一步驗證實驗）
  5. **誠實度**（承認代價、給出可推翻結論的翻盤條件）
  6. **情境貼合度**（真正契合專案硬性約束，而非套話）

## 🔍 核心差異總結

1. **拒絕套話與強迫選邊**：單一模型天然傾向「給出平衡的中立建議」，對決策者毫無指導意義；Senate 的辯手強制選邊並給出極限攻防，逼出真實邊界。
2. **數學定性 vs 人工瞎猜**：Senate 的翻盤臨界點是解析求解計算出來的（例如「當某指標權重超過 62% 時翻盤」），Baseline 只能用「如果很重視效能就可以考慮 Rust」這種模糊敘述。
3. **盲點與反向驗證實驗**：Senate 必定輸出「低成本、2 天內能做完、能推翻當前結論」的驗證實驗（Spike），讓決策具備科學可證偽性。
